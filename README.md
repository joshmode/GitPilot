# GitPilot

GitPilot is a native, AI-native GitHub project command centre. It combines
repository and project health, pull-request review, evidence-backed AI
explanations, persistent project memory and guarded automation in one Rust
desktop application.

GitHub account is connected.

## Quick start

```bash
cargo run -p gitpilot-app
```

Requirements: stable Rust (1.88+), macOS 12+ for the first-class desktop target.
The default build uses egui's native renderer and requires no Node.js runtime.

To use GitHub data, add a fine-grained PAT in **Settings → GitHub**. The token is
stored in the macOS Keychain (or an OS credential adapter on other platforms),
never in SQLite. Required read scopes are listed in the UI. AI providers are
optional until an explanation or review is requested.

## Configuration and data

Application data is stored below the OS application-data directory:

- `gitpilot.sqlite` — versioned application database
- `logs/gitpilot.log` — durable diagnostic log with redaction and bounded
  retention
- credentials — OS keychain, not the database

Set `GITPILOT_DATA_DIR` to use an isolated development profile. Set
`GITPILOT_DEMO=0` to disable seeded demo data on first launch.

## Safety principles

- Read-only by default; every GitHub mutation requires a typed confirmation.
- Credentials live in the OS keychain and are redacted from logs and errors.
- Repository text is untrusted context and can never change tool permissions.
- Local commands are structured, allow-listed specifications; there is no
  free-form shell generated by a model.
- AI output is labelled as inference and always linked to evidence when showing
  repository facts.
